# Kapetbahay

A responsive, static frontend prototype for the Kapetbahay cafe, split into two role-specific experiences:

- `customer/` is the QR-code menu and order flow.
- `staff/` is the staff sign-in and live order dashboard demo.

Open `customer/index.html` or `staff/index.html` directly in a browser. Tailwind CSS, Google Fonts, Lucide icons, and menu photography load from CDNs, so those assets need an internet connection. The forms and orders are frontend simulations only; authentication, payment, persistence, and a real kitchen order feed require a backend integration.
